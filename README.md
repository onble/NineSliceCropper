# NineSliceCropper

一个完全在浏览器本地运行的九宫格 PNG 裁剪工具。它会删除可拉伸的中间区域，将四个角重新拼接成更小的 PNG，并完整保留透明通道。

## 本地运行

```bash
npm install
npm run dev


本地局域网服务
npm run dev -- --host 0.0.0.0
```

构建与测试：

```bash
npm test
npm run build
```

## 像素坐标模型

`left` 和 `top` 分别是从源图左侧、顶部开始计算的切片坐标。`right` 和 `bottom` 是右侧切片线的 X 坐标与下侧切片线的 Y 坐标，不是边距值。所有边界均为整数像素，并满足：

```text
0 < left <= right < imageWidth
0 < top <= bottom < imageHeight
```

导出时通过四次源区域与目标区域尺寸完全相同的 `drawImage` 调用完成拼接，因此不会缩放或插值四角像素。小于 2 × 2 像素的图片可以预览，但无法形成四个非空角区域，因此不能导出。

## 切换图片时继承切片参数

上传或拖入下一张 PNG 时，同尺寸图片直接沿用上一张图片的有效切片坐标；尺寸变化时，左右切线分别按新旧宽度比例换算，上下切线分别按新旧高度比例换算。例如横向切线位于 30% 和 60% 处，换图后仍位于对应比例位置。

换算结果四舍五入到整数像素，并限制在图片内部，以保留至少 1 像素的边角。镜像模式和导出命名设置继续保留；开启镜像时，换算后仍保持左右边距对称。首次加载或上一张图片无法裁剪时使用默认切线；加载失败不会替换当前图片和切片参数。点击「重置」恢复当前图片的默认切线并关闭镜像。

## 左右对称修复

上传图片后，在「左右对称修复」中选择：

- **保持原图**：保留原来的左右像素，正常裁剪。
- **以左侧为准 → 镜像到右侧**：保留左半边，将它水平镜像到右半边。
- **以右侧为准 → 镜像到左侧**：保留右半边，将它水平镜像到左半边。

镜像不会缩放图片，保留透明通道；奇数宽度的中心列保持原样。编辑区和输出预览会立即更新。启用时，以所选一侧的切片宽度同步另一侧（最大为源图宽度的一半，向下取整）；随后拖动任一横向切片线或输入坐标，两侧会联动，保证裁剪结果和 Cocos 左右边距对称。上下切片不受影响。

点击「导出 PNG」即可得到九宫格 PNG，并继续进行无损优化。开启「添加文件名尾缀」时，镜像结果的文件名还会带有「左侧镜像」或「右侧镜像」标记。切换回「保持原图」会恢复原图像素，保留当前切片位置；「重置」同时恢复默认切片和原图。重新上传图片会保留镜像模式。

## 导出文件名

「输出结果」面板提供「添加文件名尾缀」开关，默认开启，尾缀为 `-九宫格裁剪`。开启时显示输入框，可修改包含连接符在内的完整尾缀，尾缀添加在 `.png` 之前；关闭时隐藏输入框，并按原文件名导出（不添加镜像方向标记）。

离开尾缀输入框时会校验，拒绝空白尾缀、`< > : " / \ | ? *` 和控制字符。无效内容会显示错误并阻止导出；可修改后再次离开输入框，或关闭尾缀开关。点击导出时也会校验。切换开关会保留已输入的内容，重新上传图片不重置命名设置。

## 预览缩放与平移

上方「源图片」操作窗口也支持视图调整：

- 滚动鼠标滚轮，以鼠标所在位置为中心缩放；拖动图片或空白处可平移。
- 拖动切片线仍然调整切片边界，放大或平移后也按准确的源图像素计算。
- 下方滑块和百分比同步显示缩放，范围为 10%–3200%；这里的 100% 为图片适应窗口的初始显示比例。
- 点击「居中复原」恢复初始比例并居中，只复原上方视图，保留切片、镜像设置和下方预览视图。
- 调整切片或镜像方向时保留当前视图；重新上传图片或点击顶部「重置」会复原视图。

下方「四角拼接预览」使用原始像素比例：

- 在下方「四角拼接预览」窗口内滚动鼠标滚轮，以鼠标所在位置为中心放大或缩小。
- 按住鼠标左键拖动，可移动预览图片，移出窗口后松开也会结束拖动。
- 窗口下方的滑块调节缩放比例，后面的数字同步显示当前百分比，范围为 10%–3200%。
- 点击「1:1 居中复位」，恢复 100% 原始像素比例并回到窗口中心。
- 调整切片或镜像方向时保留当前视图；重新上传图片或点击顶部「重置」会恢复 1:1 居中。

缩放与平移只影响预览，不改变图片像素、九宫格边距或导出 PNG 的尺寸。

## 无损 PNG 优化

导出时会在独立 Web Worker 中使用 OxiPNG WASM 自动优化浏览器生成的基础 PNG：

- 固定使用无损优化，不缩放、不量化颜色。
- 禁用透明像素 RGB 改写（`optimiseAlpha: false`）。
- 只有优化结果尺寸严格更小时才采用；相等或更大时保留基础 PNG。
- Worker 异常、浏览器不支持或 30 秒超时时，仍会正常导出基础 PNG。
- 界面会显示优化前后的文件体积与缩减比例。

使用的 `@jsquash/oxipng` 采用 Apache-2.0 许可证，底层 OxiPNG 采用 MIT 许可证。
